01What is JavaScript?

JavaScript (JS) is the only programming language your browser understands natively. It reads the page (the DOM), reacts to users, talks to servers, and changes everything live. Press the button — that's JS:

CODE
const btn = document.querySelector("#magic");
const out = document.querySelector("#magicOut");
let clicks = 0;

btn.addEventListener("click", () => {
    clicks++;
    out.textContent = "Clicked " + clicks +
        " time(s)!";
    btn.style.background = clicks % 2
        ? "#8250df" : "#0969da";
});
RESULT

The three web languages:

🧱 HTML — structure (the skeleton)

🎨 CSS — style (the clothes)

⚡ JS — behavior (the muscles)

Note: JavaScript ≠ Java. Java is a big server language; JavaScript is the web's own language. Don't confuse them (interviewers love this trap).

12Array Methods — map, filter, reduce

The modern way to transform arrays. These three cover 80% of real work:

CODE
const prices = [10, 25, 40];

// map: transform every item
const withTax = prices
    .map(p => p * 1.1);        // [11, 27.5, 44]

// filter: keep what matches
const big = prices
    .filter(p => p >= 20);      // [25, 40]

// reduce: combine into one value
const total = prices
    .reduce((sum, p) => sum + p, 0); // 75

// forEach: do something for each
prices.forEach(p => console.log(p));

// find & sort
prices.find(p => p > 20);   // 25
[3, 1, 2].sort((a, b) => a - b); // [1,2,3]
RESULT

Chain them: prices.filter(p => p > 10).map(p => p * 2) — each method returns a new array, so they link together like a pipeline.

15Arrow Functions — the modern style

CODE
// old style
function square(x) {
    return x * x;
}

// arrow, multi-line
const square = (x) => {
    return x * x;
};

// arrow, single expression (implicit return)
const square = x => x * x;

// one param → no parens needed
const double = n => n * 2;

// zero params → empty parens
const hi = () => "hello";

// perfect with arrays:
[1, 2, 3].map(n => n * 10); // [10,20,30]

Live: map with arrows

Which to use? Arrows are shorter and don't bind their own this (usually what you want). Function declarations are better for named, hoisted utilities. Modern code is ~90% arrows.

16Scope & Closures

CODE
// GLOBAL: visible everywhere
const app = "MyApp";

function demo() {
    // FUNCTION scope: only inside demo
    const inner = "secret";

    if (true) {
        // BLOCK scope: only inside the { }
        let blockVar = 1;
        var oldVar = 2;  // var escapes the block! (bad)
    }
    console.log(oldVar);  // 2 — visible (bad)
    // console.log(blockVar); // ERROR
}

// CLOSURE: inner fn remembers outer vars
function makeCounter() {
    let count = 0;
    return () => ++count;  // remembers count!
}
const counter = makeCounter();
counter(); // 1
counter(); // 2 — count survived
RESULT

18Destructuring & Spread

// name = "Alex", age = 21

// ARRAY destructuring

19The DOM — JavaScript sees your page

DOM = Document Object Model. When the browser reads your HTML, it builds a tree of objects — one for every tag. JavaScript can walk that tree, change it, add to it. The entry point is document:

CODE
// the document IS the page
document.title;              // page title
document.body;              // the <body> element
document.URL;               // current address

// the tree: html → body → div → p
document.body.children;     // direct kids
document.body.firstElementChild;

// every element is an object
// with properties like:
element.textContent;      // the text
element.style;            // inline CSS
element.className;        // class list
element.id;               // id

// change the page live:
document.title = "New title!";

27Event Bubbling & Delegation

Clicks travel UP the tree: click a button → its parent → grandparent… This lets you handle many elements with ONE listener (delegation) — essential for lists:

CODE
// 100 list items, ONE listener:
list.addEventListener("click", (e) => {
    const item = e.target.closest(".item");
    if (!item) return;      // not an item

    item.classList.toggle("done");
    console.log("clicked:", item.textContent);
});

// e.target = what was actually clicked
// closest() = nearest matching ancestor

// stop the trip upward if needed:
e.stopPropagation();

// and target vs currentTarget:
e.target;          // clicked element
e.currentTarget;   // element with listener

31JSON — the data language of the web

JSON is how every API talks: it's just objects/arrays as text. Two functions cover 100% of the work:

CODE

const text = JSON.stringify(user);
// '{"name":"Alex","age":21}'

// JSON string → object (from API)
const back = JSON.parse(text);
back.name;   // "Alex"

// pretty print (readable)
JSON.stringify(user, null, 2);

// an API response looks like:
{
  "users": [
    { "id": 1, "name": "Alex" },
    { "id": 2, "name": "Sam" }
  ]
}
RESULT

Edit JSON — live parse (no crash on error):

JSON rules: double quotes only (no '), no trailing commas, no comments. One mistake = parse error. JSON.parse inside try/catch is the safe pattern.

33Promises & async/await

Some work takes time (loading data, waiting for a response). Promises handle "later" — and async/await makes it read like normal code:

CODE
// a Promise = "I'll give you a value LATER"
const wait = new Promise((resolve) => {
    setTimeout(() => resolve("done!"), 2000);
});

// consume it
wait.then(result => console.log(result));

// the MODERN way: async/await
async function main() {
    const result = await wait;
    console.log(result);   // "done!"
}
main();

// error handling like try/catch
async function load() {
    try {
        const data = await fetchSomething();
    } catch (err) {
        console.error(err);
    }
}
RESULT

A real 2-second promise — watch the button:

idle
Why it matters: while the promise waits, the page keeps responding. That's how apps load data without freezing. `await` only works inside `async` functions.

34Fetch — talk to the internet

fetch() requests data from a URL — an API, a file, your own server. This demo loads real data from a free public API:

CODE
async function loadUsers() {
    try {
        const res = await fetch(
            "https://jsonplaceholder."
             + "typicode.com/users");
        if (!res.ok) throw new
            Error("HTTP " + res.status);
        const users = await res.json();
        console.log(users[0].name);
    } catch (err) {
        console.error("fetch failed", err);
    }
}

// POST data:
const res = await fetch("/api/save", {
    method: "POST",
    headers: { "Content-Type":
        "application/json" },
    body: JSON.stringify({ name }),
});

Everything you learned, in one app: variables, functions, arrays, the DOM, events, and localStorage. This is the first app every developer builds:

CODE
// 1. state = an array of tasks
let tasks = [];

// 2. add a task
function addTask() {
    const input =
        document.querySelector("#taskInput");
    const text = input.value.trim();
    if (!text) return;
    tasks.push({ text, done: false });
    input.value = "";
    render();
}

// 3. render the list
function render() {
    const list =
        document.querySelector("#taskList");
    list.innerHTML = "";
    tasks.forEach((task, i) => {
        const li = document
            .createElement("li");
        li.textContent = task.text;
        li.onclick = () => {
            task.done = !task.done;   // toggle
            render();
        };
        if (task.done) li.classList
            .add("done");
        list.appendChild(li);
    });
}

// 4. save between visits
localStorage.setItem("tasks",
    JSON.stringify(tasks));
